# Мій сайт-портфоліо

## Що де лежить

```
index.html   ← каркас сторінки та ефекти (зазвичай не чіпаєш)
style.css    ← дизайн: кольори, шрифти, розміри
content.js     ← УСІ тексти сайту українською (це редагуєш ти)
content-en.js  ← ті самі тексти англійською
images/      ← картинки: скріншоти проєктів, og.jpg (прев'ю посилання)
```

---

## Як редагувати тексти

Відкрий `content.js` у будь-якому редакторі (VS Code, Notepad++, навіть у браузері на GitHub)
і міняй тільки те, що **в лапках**.

| Що змінити | Де в `content.js` |
|---|---|
| Ім'я, роль, місто | `name`, `role`, `location` |
| Великий заголовок | `headline` |
| Текст про себе | `intro` |
| Слова в біжучому рядку | `marquee` |
| Цифри-лічильники | `stats` |
| Проєкти | `projects` |
| Навички | `skills` |
| Досвід | `experience` |
| Відгуки | `testimonials` (поки порожньо — секцію не видно) |
| Часті питання | `faq` |
| Пошта і соцмережі | `contacts` |

### Додати новий проєкт
1. У `projects` скопіюй цілий блок `{ ... },` одного з проєктів.
2. Встав його нижче і зміни тексти.
3. **`slug`** має бути унікальним, латиницею, без пробілів (напр. `"shop-bot"`) —
   це адреса сторінки проєкту: `сайт/#p-shop-bot`.

### Додати скріншот проєкту
1. Поклади картинку в папку `images/`, напр. `images/hotel.png`.
2. У проєкті напиши `image: "images/hotel.png"`.
3. Додаткові скріншоти для сторінки проєкту — у `details.gallery`:
   `gallery: ["images/hotel-1.png", "images/hotel-2.png"]`.

### Додати відгук
```js
testimonials: [
  { text: "Текст відгуку", name: "Ім'я", role: "Хто ця людина" },
],
```

### Важливо
- Кожен блок `{ ... }` у списку закінчується комою.
- Лапки всередині тексту: якщо пишеш `Ім'я` — апостроф можна, а подвійні лапки `"` всередині — не можна (заміни на «ялинки»).
- Якщо після зміни сайт став порожнім — найчастіше десь зникла кома або лапка.

## Англійська версія
- Перемикач **UA / EN** — у меню біля тем. Сайт сам відкривається англійською для людей,
  у яких браузер не українською/російською, і запам'ятовує вибір.
- Посилання одразу на англійську версію: `https://rkpvrkddsb-sketch.github.io/?lang=en`
- Тексти про тебе й проєкти англійською — у `content-en.js`.
  Структура така сама, як у `content.js`. **`slug` і `project` мають збігатися** в обох файлах.
- Додаєш новий проєкт — додай його в обидва файли.
- Підписи кнопок і заголовків секцій («Вибрані проєкти», «Детальніше»…) — в `index.html`, блок `I18N`.

## Як змінити кольори

У `style.css` на самому початку є блоки з кольорами для кожної теми:
- `body[data-accent="orb"]` — «Сяйво»
- `body[data-accent="glow"]` — «Ніч»

`--accent` — головний колір, `--accent-2` — другий.

## Налаштування ефектів (в `index.html`)
- `SNAP_ZONE` — з якої відстані курсор примагнічується до кнопок (px)
- `SNAP_FOLLOW` — наскільки курсор ворушиться всередині кнопки
- `TILT` — нахил карток проєктів (градуси)

## Заставка
При першому вході перо «креслить» логотип j13 на аркуші в клітинку, логотип перелітає в меню.
При перезавантаженні — коротке «Завантаження…». Швидкість пера — `SPEED` в `index.html`.
Показується раз за відвідування. Подивитись ще раз: додай `?intro` до адреси —
`https://rkpvrkddsb-sketch.github.io/?intro`

## Як запускали на GitHub Pages (для довідки)

1. Зареєструйся на **github.com** (якщо ще немає акаунта).
2. Натисни **New repository**. Назва: `ТВІЙ-НІК.github.io`
   (замість ТВІЙ-НІК — твій логін на GitHub). Тип — **Public**. Створи.
3. На сторінці репозиторію: **Add file → Upload files**.
   Перетягни всі файли й папку `images` з цього архіву. Натисни **Commit changes**.
4. Зайди в **Settings → Pages**. У «Source» вибери **Deploy from a branch**,
   гілка **main**, папка **/ (root)** → **Save**.
5. Через 1–2 хвилини сайт буде на адресі **https://ТВІЙ-НІК.github.io**

### Сайт уже запущено
Адреса: **https://rkpvrkddsb-sketch.github.io**

Оновлювати сайт: відкриваєш файл на GitHub → значок олівця ✏️ → редагуєш → **Commit changes**.
Через хвилину-дві зміни вже на сайті.

### Свій домен (за бажанням)
Купуєш домен (напр. на Namecheap / Cloudflare, ~10 $/рік), у **Settings → Pages → Custom domain**
вписуєш його і налаштовуєш DNS за підказками GitHub.

## Мови
Сайт сам визначає мову браузера: українська (`content.js`), англійська (`content-en.js`), іспанська, німецька, французька, польська, португальська, італійська (`content-es.js`, `content-de.js`, `content-fr.js`, `content-pl.js`, `content-pt.js`, `content-it.js`). Якщо мова браузера інша — відкривається англійська.
Угорі перемикач: «мова відвідувача ↔ EN». Перевірити мову вручну: `?lang=es`, `?lang=de` тощо.
Коли змінюєш текст у `content.js`, не забудь поправити його й в інших мовних файлах.
